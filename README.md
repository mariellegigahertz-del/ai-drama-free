# AI Drama Free

AI Drama Free is a free, installable web app designed for Android phones. The starter catalog is illustrative only; it does not include real videos or claim any reuse rights. Add clips you have permission to use, with a direct HTTPS video link and the license/permission page. Saved items and your library are stored locally in the browser on that device.

## Install on Android

1. Publish these files to any static web host that serves them over HTTPS.
2. Open the hosted address in Chrome on your Android phone.
3. Use Chrome's **Install app** or **Add to Home screen** option.

The app shell works offline after it has loaded once. Video playback/download still depends on the external video host and its permissions. The app does not verify license links, and users must follow attribution and other license conditions.

## Local preview

Serve this folder with any static HTTP server and open its local address in a browser. Service workers and install prompts require HTTPS or localhost.
